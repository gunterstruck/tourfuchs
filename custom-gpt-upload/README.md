# TourFuchs - Export fuer Guided Agent / Custom GPT

Generierter Uploadstand: Wissensbasis 3.28, App 3.7.0.

Diese Kopien nicht direkt bearbeiten. Die Quellen liegen unter `docs/` sowie im Repository-Stamm. Nach jeder Aenderung zuerst `npm run docs:pdf` und danach `npm run docs:gpt-upload` ausfuehren.

1. Den Inhalt von `custom-gpt-systemprompt.txt` in das Feld fuer die Anweisungen kopieren.
2. Die vier Markdown-Dateien und die PDF als Wissen hochladen (nicht `EINSTELLUNGEN.md` und nicht diese README).
3. Name, Beschreibung und Gespraechsaufhaenger aus `EINSTELLUNGEN.md` uebernehmen.
4. Eine kurze Testfrage stellen, zum Beispiel: "Wie plane ich unterwegs eine Tour und hole mir davor ein Briefing?"

Custom GPTs werden am 11.12.2026 abgeschaltet; die Umstellung auf ein Plugin steht in `EINSTELLUNGEN.md`.

Die PDF enthaelt zusaetzlich den visuellen Bildanhang. Alle Schulungsbilder verwenden ausschliesslich Demo- oder synthetische Daten.
